# Student Management System

## Project Description
This is a Python-based Student Management System that allows users to add, view, search, and delete student records. The project uses Object-Oriented Programming (OOP), file handling, exception handling, and Git & GitHub.

## Features
- Add Student
- View Students
- Search Student
- Delete Student
- File Handling
- OOP Concepts

## Technologies Used
- Python 3
- Visual Studio Code
- Git
- GitHub

## Python Concepts Used
- Variables
- Data Types
- Functions
- Loops
- File Handling
- OOP
- Exception Handling

## Installation
Open the project in VS Code.

## How to Run

```bash
py main.py
```
